Overview

Description

This project brings together all aspects of your computer vision solution. Your project should demonstrate the integration of multiple computer vision techniques (e.g., object detection, image segmentation, classification, or tracking) to create a comprehensive end-to-end solution. The focus is on practical application, demonstrating your ability to move from problem definition through data preparation, model development, evaluation, and deployment.

Submission Requirements

  • Technical Documentation & Code Repository (Jupyter Book, folder of Colab Notebooks, or both)
  • Technical Synopsis (PDF format, STRICT two-page limit)
  • Demo Video (5-8 minutes)
  • Management Presentation (PowerPoint/Google Slides, 12-15 slides)

All deliverables should be uploaded individually to Canvas.

Assignment Tasks

  1. Technical Documentation & Code Repository
    • Develop well-documented, reproducible code with clear explanations covering the complete pipeline from data loading through model inference.
    • Include all preprocessing, training, evaluation, and inference code.
    • Share published Jupyter Book.
  1. Technical Synopsis (Two-Page PDF)
    • Problem statement and objectives
    • Dataset description and preprocessing approach
    • Mathematical foundations and model architectures used
    • Training methodology and hyperparameter choices
    • Evaluation metrics with detailed results and analysis
    • Performance benchmarks (accuracy, precision, recall, F1, mAP, IoU, etc.)
    • Comparison with baseline or alternative approaches
    • Challenges encountered and solutions implemented
  1. Demo Video (5-8 minutes)
    • Record a video demonstration showcasing your computer vision system performing real-time or batch inference.
    • Include multiple test cases, including edge cases.
    • Narrate the video to explain what is happening and highlight key features and capabilities.
    • Discuss model performance and interesting observations.
    • Include brief introduction and conclusion.
    • Post video to Module 10 Demo Video Discussion Forum.
  1. Management Presentation (12-15 slides)
    • Create a presentation for non-technical stakeholders (Business leaders, Senior management, or Consulting clients).
    • ALL team members must present at least one section.
    • Required Slide Structure:
      1. Executive Summary (1 slide)
      2. Present problem statement in business terms, solution overview, key results, and business value/impact.
      3. Team Introduction (1 slide)
      4. Problem Statement (1-2 slides)
      5. Data Profile (1-2 slides) - Describe dataset size/composition, data sources/formats, etc.
      6. Exploratory Data Analysis (1-2 slides) - Present key findings through visualizations, data distribution/patterns, and insights that informed modeling decisions.
      7. Technology Platform & Solution Architecture (1-2 slides) - Include high-level system architecture diagram, tools/frameworks/technologies used, cloud services or infrastructure, and deployment approach.
      8. Methodology (1-2 slides) - Explain computer vision techniques employed, model selection rationale, training approach (transfer learning, custom models, etc.), and key architectural decisions.
      9. Literature Review & References (1 slide) - Discuss related work, academic papers reviewed, industry benchmarks, and how your approach builds on existing research.
      10. Results & Evaluation (1-2 slides) - Present performance metrics with visualizations, comparison to baseline/industry standards, success stories, example predictions, and limitations/areas for improvement.
      11. Next Steps & Path to MVP (1 slide) - Outline immediate next steps for productionization, recommended improvements, timeline/resource requirements, and scalability considerations.
      12. Appendix (1-2 slides, optional) - Include additional technical details, extended results/analysis, and backup slides for Q&A.
